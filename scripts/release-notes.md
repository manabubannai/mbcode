# Zen Code v1.8.0

文字選択の不具合を直し、ランチャーを独立アプリ「Zen Launcher」に切り離しました。

- **ターミナル内の文字が選べない不具合を修正（v1.8.0）**: ①Claude Code など「マウスを使うアプリ」の実行中はドラッグが選択にならず、出力が流れるたびに選択が消えていた → マウス操作はターミナル側（文字選択）を既定にした ②ウィンドウの余白からドラッグを始めると何も選べなかった → 余白も選択できるようにした。vim などにマウスを渡したいときは View メニュー「マウス操作をアプリに渡す」（⌥⌘M）でON

- **Zen Launcher（新アプリ・v1.0.0）**: メニューバー常駐の軽量ランチャー。⇧⌘Space でどこからでもプロジェクトを検索し、Enter で Zen Code のターミナルが開く（Alfredスタイル）。ログイン時に自動起動
- **Zen Code はふつうのターミナルに戻りました**: バックグラウンド常駐とログイン時自動起動を廃止（旧版で登録されたログイン項目は初回起動時に自動解除）。⌘K のアプリ内ランチャーと ⌥Space の Quake ターミナルはそのまま
- **タブ名の変更**: タブのダブルクリックまたは ⇧⌘R で名前を付けられる。空欄で自動タイトルに戻る
- **タイル表示（新機能・デフォルトON）**: ウィンドウが２枚以上あるとグリッド状に自動整列。AIの作業が完了したターミナルは自動で左上に移動し、タイトルに ✅ が付く（そのウィンドウを見たら消える）。⌥⌘T で手動整列、View メニューの「自動で並べる」でON/OFF
- 修正: ランチャーの外をクリックするとランチャーが閉じるように
- ファイル/スクショのドラッグ&ドロップ対応（v1.5.0〜1.6.x の未公開分を含む）

## ダウンロード

`ZenCode.zip` と `ZenLauncher.zip` をダウンロード → 解凍してアプリケーションフォルダへ。Developer ID 署名 + Apple 公証済み。
