# Zen Code v1.6.0

アプリを開いていなくてもランチャーが使えるようになりました。

- **バックグラウンド常駐 + ログイン時自動起動**: 初回起動時にログイン項目へ自動登録（システム設定 > ログイン項目）。Macにログインした瞬間からウィンドウなしで常駐し、⇧⌘Space のランチャーと ⌥Space のQuakeターミナルがいつでも使える
  - 最後のウィンドウを閉じるとDockから消えてバックグラウンドに戻る（アプリは終了しない。⇧⌘Space で即復帰）
  - オフにしたい場合はメニュー「ログイン時に自動起動（バックグラウンド常駐）」またはシステム設定から
- **ファイル/スクリーンショットのドラッグ&ドロップ**（v1.5.0）: Finderのファイルやスクショのサムネイルをターミナルにドロップすると、パスがクォート付きで入力欄に入る（通常ウィンドウ・Quakeターミナル両対応）

## ダウンロード

`ZenCode.zip` をダウンロード → 解凍してアプリケーションフォルダへ。Developer ID 署名 + Apple 公証済み。

## 動作環境

macOS 13 Ventura 以降
